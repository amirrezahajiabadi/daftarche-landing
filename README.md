# دَفتَرچه — صفحهٔ معرفی

صفحهٔ فرود (Landing) دَفتَرچه. این مخزن مستقل است و هیچ وابستگی زمان‌اجرا به
برنامهٔ وب دَفتَرچه ندارد؛ فقط فایل‌هایی را در خود دارد که همین صفحه واقعاً
استفاده می‌کند.

## معماری

| دامنه | محتوا |
| --- | --- |
| دامنهٔ اصلی (`/`) | همین صفحهٔ معرفی |
| `app.<DOMAIN>` | برنامهٔ وب دَفتَرچه |

## اجرای محلی

از ریشهٔ همین پوشه یک سرور ساده اجرا کن و `/` را باز کن:

```bash
python -m http.server 8011 --bind 127.0.0.1
# http://127.0.0.1:8011/
```

صفحه از مسیر `/` سرو می‌شود؛ همهٔ مسیرها (CSS، JS، فونت، تصویر و SVG) نسبی و
مستقل از زیرمسیر هستند.

## اتصال دکمه‌های «ورود به دَفتَرچه»

مقصد ورود به برنامه یک مقدار مشخص و قابل تنظیم است و هنوز دامنهٔ واقعی در آن
نوشته نشده:

- تنها محل ویرایش: `js/config.js` → مقدار `DAFTARCHE_APP_URL`.
- همان مقدار به‌صورت placeholder در `index.html` روی هر `[data-app-link]` هم
  هست تا صفحه با جاوااسکریپت خاموش هم کار کند.
- وقتی برنامه روی `app.<DOMAIN>` منتشر شد، فقط `daftarche.example` را در
  `js/config.js` با دامنهٔ واقعی عوض کن.

نشانی خودِ این صفحه برای خزنده‌ها و کارت‌های اجتماعی (canonical و og) هم
placeholder دارد و باید در `index.html` با دامنهٔ واقعی جای‌گذاری شود.

## اندروید / بازار / مایکت

نسخهٔ اندروید هنوز منتشر نشده؛ بنابراین هیچ‌کدام از این مقصدها لینک فعال
نیستند. دکمهٔ اندروید یک `span` غیرقابل‌فوکوس با برچسب «به‌زودی» است و جای
لینک فروشگاه‌ها در `platforms` خالی مانده تا روز انتشار APK پر شود.

## ساختار

```
index.html                 صفحهٔ معرفی (دامنهٔ اصلی)
css/base.css               پایهٔ طراحی: فونت‌ها، توکن‌ها، reset، کاغذ و گرین راهنما
css/landing.css            استایل مخصوص همین صفحه
js/config.js               یک مقدار قابل تنظیم: نشانی برنامهٔ وب
js/landing.js              بهبودهای تدریجی: آشکارسازی اسکرول، هدر، منوی موبایل
assets/fonts/              دو فایل فونت Estedad
assets/icons/              favicon، apple-touch-icon و آیکن اشتراک‌گذاری
assets/screenshots/        تصاویر واقعی محصول (امروز، فهرست، تمرکز)
assets/characters/         اسپرایت شخصیت‌های استفاده‌شده
```

## دسترس‌پذیری و حرکت

- `lang="fa"` و `dir="rtl"` در کل صفحه.
- لینک پرش به محتوا، ترتیب فوکوس منطقی و حلقهٔ فوکوس روشن روی گرین.
- بدون جاوااسکریپت هم صفحه کامل، خوانا و قابل ناوبری است.
- با `prefers-reduced-motion: reduce` همهٔ حرکت‌های تزئینی خاموش می‌شوند.

## استقرار

مخزن یک سایت ایستا است: تمام محتوای ریشه را همان‌طور که هست روی میزبان ایستا
(GitHub Pages، Netlify، Cloudflare Pages و مانند آن) منتشر کن. هیچ مرحلهٔ ساخت
و هیچ وابستگی نصب‌شدنی وجود ندارد.
